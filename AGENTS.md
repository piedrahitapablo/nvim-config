# AGENTS.md

## Commit Message Rules

- Start with lowercase
- Use infinitive form (e.g., "add" instead of "adding" or "added")

### Examples

✅ Good:
- add basedpyright LSP configuration
- fix hover styles
- update plugin versions

❌ Bad:
- Add basedpyright LSP configuration
- adding basedpyright LSP configuration
- added basedpyright LSP configuration
